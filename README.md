Mums-recept-app

Mums är en mobilapplikation för att söka och samla recept.  Utvecklad som ett utbildningsprojekt med React Native och Expo för frontend, Supabase för backend. 

Appen tillåter alla användare att:
-	Söka och se offentliga recept
-	Dela recept genom att öppna telefonens delningsfunktion
-	Skapa konto och logga in
Inloggade användare kan även:
-	Skapa egna recept
-	Lägga till och ta bort recept från favoriter
-	Logga ut


Det går att skapa konto med en fiktiv email då inställningen för närvarande inte kräver e-post verifikation.
